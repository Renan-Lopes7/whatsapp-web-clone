# 💬 WhatsApp Web Clone
 
Clone da interface do WhatsApp Web desenvolvido com HTML e CSS puro, design fiel à versão original. Projeto focado em práticas de front-end, posicionamento CSS e estruturação semântica.

👉 [Acesse o projeto ao vivo](https://renan-lopes7.github.io/whatsapp-web-clone/)
 
## ⚙️ Funcionalidades
 
- Sidebar com perfil e notificações
- Lista de conversas com indicadores de mensagens não lidas
- Layout fiel à interface do WhatsApp Web
## 🚀 Como rodar o projeto
 
```bash
# Clone o repositório
git clone https://github.com/Renan-Lopes7/whatsapp-web-clone.git
 
# Acesse a pasta
cd whatsapp-web-clone
```
 
Abra o arquivo `index.html` no navegador — sem necessidade de instalar nada!
 
## 🛠️ Tecnologias
 
- **HTML5** — estruturação semântica
- **CSS3** — estilização e posicionamento
